# Scout Extended Coverage — Идея

> Статус: ИДЕЯ (backlog, не для немедленной реализации)
> Дата: 2026-02-27

## Проблема

Scout сейчас собирает только "верхушку" проектов с каждой платформы:
- Kwork: только 1 страница результатов
- Freelancer: limit=20 (API поддерживает до 100)
- FL.ru: только `all.xml` (общий RSS)
- Telegram: нет бэкфилла при старте listener

Это приводит к пропуску релевантных проектов, особенно в нишевых категориях.

## Уровень 1: Quick Wins

### Kwork — пагинация
- Сейчас: `page=1` (≈48 проектов)
- Улучшение: `page=2, 3` — x3 покрытие
- Риск: rate limiting (добавить задержки 2-3с между страницами)

### Freelancer — увеличить limit
- Сейчас: `limit=20`
- Улучшение: `limit=100` — x5 покрытие за один запрос
- Риск: минимальный, API поддерживает

### FL.ru — категорийные RSS
- Сейчас: `https://www.fl.ru/rss/all.xml`
- Улучшение: отдельные фиды по категориям:
  - `web-development.xml`
  - `design.xml`
  - `mobile.xml`
  - `marketing.xml`
- Риск: нужно найти актуальные URL фидов

### Telegram — бэкфилл при старте
- При запуске listener: загрузить сообщения за последние 30 дней
- Telethon: `client.get_messages(channel, limit=100, offset_date=...)`
- Дедупликация через хэш в Valkey SET (уже в плане)

### last_fetched_at tracking
- Новое поле в БД: `platform_fetch_status(platform, last_fetched_at, last_count, gaps)`
- При каждом fetch: обновлять timestamp
- Алерт если платформа не опрашивалась >2ч

## Уровень 2: Улучшенный сбор

### Сортировка по дате
- Freelancer API: `sort_field=time_submitted&sort_direction=desc`
- Kwork: сортировка по новизне (если доступно)
- Цель: не пропускать свежие проекты между циклами

### Offset-пагинация
- Запоминать последний seen project ID
- При следующем fetch: начинать с offset
- Предотвращает повторную обработку

## Уровень 3: Новые платформы

### YouDo
- Категории: IT, дизайн, маркетинг
- Метод: RSS или скрапинг (нет публичного API)
- Объём: ~50-100 заказов/день в IT

### Profi.ru
- Категории: IT-услуги, веб-разработка
- Метод: скрапинг (закрытый API)
- Риск: более строгий anti-bot

## Оценка

| Уровень | Усилия | Импакт |
|---------|--------|--------|
| 1 (Quick Wins) | 2-3 часа | x3-5 покрытие |
| 2 (Улучшенный сбор) | 4-6 часов | -50% пропущенных проектов |
| 3 (Новые платформы) | 2-3 дня | +2 источника |
