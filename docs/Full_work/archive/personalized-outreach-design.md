# Персонализированный Multi-Channel Outreach — Дизайн

> Brainstorm-сессия 2026-02-24. Статус: **дизайн утверждён**, реализация не начата.

## Обновлённый Pipeline B

**Текущий (до изменений):**
```
GeoScout → Outreach (находит email, LLM пишет generic письмо) → [HITL] → отправка
```

**Новый:**
```
GeoScout (города РФ где ты бываешь)
    │
    ▼
Business Analyzer (НОВЫЙ)
    │ быстрый скан всех → глубокий аудит "горячих"
    ▼
Lead Scorer
    │ score → глубина анализа → приоритет канала
    ▼
Outreach Agent (ОБНОВЛЁННЫЙ)
    │ генерирует ЧЕЛОВЕЧНОЕ сообщение под канал
    │ Telegram / WhatsApp / Email — разный формат
    ▼
[HITL] — проверка каждого сообщения
    ▼
Отправка через выбранный канал
    │
    ▼
Touch Sequence Manager (НОВЫЙ)
    │ День 1 → День 3 → День 5 → Стоп
    │ Один "нет" или игнор на 2й касание = стоп навсегда
    ▼
CRM (результат: конверсия / отказ / игнор)
```

## Business Analyzer (новый шаг)

Автоматически собирает данные о бизнесе для персонализации. GeoScout даёт только название, адрес, категорию, наличие сайта — этого мало. Business Analyzer добирает остальное.

### Офлайн-бизнесы (рестораны, салоны, магазины)

```
1. Google Maps / 2GIS:
   - Рейтинг и количество отзывов
   - Фото заведения
   - Часы работы
   - Категория (ресторан, кафе, барбершоп...)

2. Соцсети (Instagram, VK):
   - Есть ли аккаунт? Сколько подписчиков?
   - Последний пост когда был?
   - Активность (мёртвый аккаунт = сильный аргумент)

3. Сайт (если есть):
   - Мобильная версия? (Lighthouse score)
   - Скорость загрузки
   - SSL сертификат?
   - Дизайн устарел? (по году в footer)
```

### Онлайн-бизнесы (интернет-магазины, SaaS, блогеры)

```
1. Сайт:
   - PageSpeed / Lighthouse аудит
   - SEO: мета-теги, sitemap, robots.txt
   - Технологии (BuiltWith / Wappalyzer)

2. Трафик:
   - SimilarWeb (приблизительный трафик)

3. Соцсети:
   - Те же проверки
```

## Lead Scorer — система скоринга

### Таблица очков

| Критерий | Очки |
|----------|------|
| Нет сайта вообще (максимальная потребность) | +3 |
| Сайт есть, но без мобильной версии | +2 |
| Много отзывов + высокий рейтинг (бизнес живой и прибыльный) | +2 |
| Есть соцсети но мёртвые (давно не постили) | +1 |
| Высокочековая категория (ресторан, клиника, салон) | +1 |
| Мало отзывов (бизнес может быть мёртвый) | -1 |
| Уже есть хороший сайт (низкая потребность) | -2 |

### Пороги и глубина анализа

| Score | Температура | Глубина анализа |
|-------|-------------|-----------------|
| ≥ 5 | Горячий | Глубокий аудит (2-3 мин) |
| 3-4 | Тёплый | Средний аудит (30 сек) |
| < 3 | Холодный | Только быстрый скан, generic письмо |

---

## Адаптивный анализ (3 тира)

| Тир | Время | Что делает |
|-----|-------|-----------|
| Быстрый скан | 5 сек | Только есть/нет сайт, соцсети, рейтинг. Дёшево, масштабируемо |
| Средний аудит | 30 сек | Быстрый скан + Lighthouse, проверка соцсетей, базовый SEO |
| Глубокий аудит | 2-3 мин | Всё выше + технологии, трафик, конкуренты в районе |

Решение: **адаптивный** — быстрый для всех, глубокий только для "горячих" лидов.

## Каскад касаний (РФ, 10 дней)

```
День 1:  Лучший доступный канал
         WhatsApp (если есть номер) > Telegram > Email
День 3:  Нет ответа → второй канал (мягкий follow-up)
День 5:  Нет ответа → последний канал (финальное)
День 10: Стоп. Пометка "не заинтересован"
```

**Стоп-правило:** один "нет" или "не интересно" на любом этапе → СТОП навсегда.

### Каналы

| Канал | Как найти контакт | Ограничения | Сложность |
|-------|------------------|-------------|-----------|
| Email | Enrichment waterfall (уже есть) | Спам-фильтры, warm-up 6 нед. | Уже реализовано |
| WhatsApp | Номер телефона (из карт/сайта) | Business API платный, шаблоны нужно одобрить | ~$0.05/сообщение, open rate 98% |
| Telegram DM | Username или телефон | Flood-wait бан при массовых DM, Telethon уже есть | Бесплатно, риск бана |
| LinkedIn | Имя + компания | InMail платный, лимит ~50/мес, скрапинг = бан | Отложен |

## Этика общения

### 7 принципов тона

1. **"Сосед, не продавец"** — живой тон, без корпоратива
2. **Без шаблонов** — каждое сообщение уникальное с деталями про конкретный бизнес
3. **Короткие сообщения** — 2-3 предложения, если интересно — расскажем подробнее
4. **Без давления** — follow-up мягкий
5. **Честность** — никогда не скрывать что это предложение услуг
6. **Один "нет" или игнор = стоп навсегда** — пометить в CRM "отказ"
7. **Без ИИ-маркеров** — живой язык, как будто реальный человек написал

### Нельзя

- "Здравствуйте, мы делаем сайты, хотите?" (generic спам)
- Писать повторно если сказали "нет"
- Писать в личку владельцу если есть бизнес-аккаунт
- Больше 3 касаний одному лиду
- Массовая рассылка одинакового текста
- "Успейте! Скидка 50% только сегодня!"
- "Напоминаю о своём предложении..." (follow-up с давлением)
- Притворяться другом/клиентом
- "Может передумали?"
- "Я провёл анализ вашего бизнеса и выявил..."
- "Позвольте предложить оптимальное решение..."

### Нужно

- **Конкретика:** "Увидел что у «Пушкинъ» 4.8 на Яндекс.Картах, но нет сайта для онлайн-бронирования"
- **Ценность:** "Рестораны с сайтом получают +30% бронирований"
- **Уважение:** "Если не интересно — не буду беспокоить"
- **Честность:** не скрывать что это предложение услуг
- **Лёгкий выход:** одно "нет" = навсегда стоп

## Примеры сообщений

### Telegram (ресторан "Пушкинъ", Арбат, рейтинг 4.8)

```
Привет! Ем у вас раз в неделю, всё нравится 👍
Заметил что нет сайта для бронирования —
гости пишут в отзывах что неудобно звонить.
Делаю такие штуки, могу показать примеры.
Если не актуально — без проблем!
```

### WhatsApp (салон красоты "Bloom", Тверская)

```
Добрый день! Видел ваш салон на Тверской —
красивый инстаграм! Но заметил что записаться
онлайн некуда, только звонок. Могу сделать
простую страницу с онлайн-записью за пару дней.
Интересно — напишите, нет — удачи вам!
```

### Email (автосервис, Химки)

**Тема:** `Онлайн-запись для вашего сервиса`

```
Здравствуйте! Нашёл ваш сервис на Яндекс.Картах —
хорошие отзывы. Заметил что записаться можно только
по телефону.

Делаю простые сайты с онлайн-записью для автосервисов —
клиентам удобнее, вам меньше звонков.

Если интересно — могу показать пример за 2 минуты.
Если нет — извините за беспокойство.

Хорошего дня!
```

## Ключевые решения

- **Фокус — Россия**, города где пользователь реально бывает/знает
- **Международный рынок — потом**, другой подход (не geo, а платформенный поиск)
- **Мессенджеры приоритетнее email** для РФ (WhatsApp > Telegram > Email)
- **LinkedIn отложен** — сложно, дорого, мало ценности для РФ-рынка сейчас
- **Адаптивная глубина анализа** — не тратить время на холодных лидов
- **HITL обязательна** на каждое сообщение (MVP), автоматизация касаний только в фазе 3
