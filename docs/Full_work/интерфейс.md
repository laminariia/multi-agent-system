## Визуальный стиль

**Атмосфера:** Command Center — строгий, контрастный, акцент на данные, без визуального шума.

**Стиль:** Modern Bento UI + минимальный Glassmorphism + Dark Mode First.

**Принципы:**
- Скругленные углы (`rounded-xl` / `rounded-2xl`) для Bento-карточек
- Глубина через тонкие рамки (`border`) и свечение (`glow`/`ring`) — не тени
- Полупрозрачные карточки (`bg-slate-900/50`) с `border border-slate-800`
- При наведении: `hover:bg-slate-800/50`
- Прогрессивное раскрытие (Progressive Disclosure): макро-уровень (dashboard) -> микро-уровень (job detail) -> артефакты (drawer)

**Типографика:**
- Метрики: `text-4xl font-semibold tracking-tight tabular-nums` (цифры не прыгают при обновлении)
- Заголовки карточек: `text-lg font-medium`
- Бейджи и теги: `text-xs font-medium uppercase tracking-wider`
- Код/сниппеты: `font-mono text-sm text-slate-300 bg-slate-900 p-3 rounded-md`

```
+-----------------+------------------------------------+
|  AGENT FLEET    |  АКТИВНЫЕ ЗАКАЗЫ                   |
|  [Scout] [Bid]  |  "React landing"   -> Critic 75%   |
|  [Dev] [Critic] |  "TG-бот"         -> Planner 25%   |
|  [Design] ...   |  "WordPress site"  -> Packager 90% |
+-----------------+------------------------------------+
|  PIPELINE B     |  ACTIVITY FEED                     |
|  Лиды: 234      |  Scout нашёл 3 заказа      2m ago  |
|  Контакт: 45    |  Bid отправил предложение  5m ago  |

+-----------------+------------------------------------+
```

**Секции:**

1. **MetricCards (6):** Active Jobs, Pending HITL, Agents Online, Resolved Today, Revenue, Orchestrator Status
2. **HITL-виджет:** top-3 pending items с inline approve/reject кнопками (без перехода на /hitl)

4. **Agent Fleet:** сетка из 10 аватарок агентов с индикацией статуса (см. Agent Fleet ниже)
5. **Pipeline B summary:** горячие лиды, активные сделки, конверсия
6. **Activity Feed:** лента последних событий агентов (real-time через WebSocket)
7. **Charts:** Jobs by Platform (bar), HITL by Type (bar), Agent Status (pie), HITL Trends (7 дней)
8. **Upcoming Actions:** дедлайны, предстоящие delivery, expiring HITL
9. **Onboarding checklist:** показывается когда нет данных (API key -> platform account -> first scan)

### 2. Jobs (`/jobs`)

Все найденные заказы со скорингом.

**Два таба:**

**"Могу сам"** (score >= 0.7) — карточки с зелёным акцентом:
- Left border accent: `border-l-4 border-l-emerald-500`
- `score_reason` badge: `bg-emerald-500/10 text-emerald-400 border border-emerald-500/20`
- Capability report для нестандартных заказов (accordion)
- Кнопки: Approve -> Bid | Reject | Later

**"Нужен разбор"** (0.5-0.7) — карточки с жёлтым акцентом:
- Left border accent: `border-l-4 border-l-amber-500`
- `score_reason` badge: `bg-amber-500/10 text-amber-400 border border-amber-500/20`
- Объяснение сомнений от AI
- Кнопки: В очередь Bid | Reject | Later

**Карточка заказа:** тёмный фон (`bg-slate-900`), title, platform badge, budget, стек, `score_reason`, score, ссылка на оригинал.

**Фильтры:** status tabs (All, New, Qualified, Bid Sent, In Progress, Completed, Disqualified), platform dropdown, search, sort (date, score, budget, title).

**Действия:** Scan Now, CSV export.

### 3. Job Detail (`/jobs/:id`)

Полная информация о заказе + прозрачная фабрика.

**Pipeline Progress Bar (Stepper):**
```
  [Design]  ----  [Dev]  ----  [Content]  ----  [Critic]
     v              >>           --              --
   Done          In Progress    Waiting         Waiting
                  60%
```
- Пройденные этапы: закрашены primary, иконка галочки
- Текущий этап: пульсирует (`animate-pulse`), аватарка агента, подпись "%"
- Будущие этапы: серые, `opacity-40`

**Task List (дерево задач Planner'а):**
Раскрывающийся список (Accordion). Каждая задача:
- Аватарка ответственного агента
- Статус: done / in progress (spinner) / waiting (часы)
- Оценка времени ("API endpoints — 2ч")
- Клик на выполненную задачу -> Artifact Drawer (результат работы агента)

**Artifact Drawer (результат работы конкретного агента):**
- Design Agent: галерея сгенерированных мокапов/изображений
- Content Agent: текстовый редактор (read-only или edit) с SEO-текстами, микрокопирайтингом
- Dev Agent: мини-IDE с деревом файлов и подсветкой синтаксиса (Monaco-style)
- Critic Agent: Audit Report — список найденных багов, уязвимости, лог ревизий ("завернул код Dev Agent'а 2 раза, потому что...")
- Packager Agent: кнопка "Скачать ZIP" / ссылка на деплой + текст сопроводительного письма

**Semantic Diff Viewer (при Critic Escalation):**
- Стиль GitHub PR: слева старый код, справа новый
- Проблема подсвечена красным
- AI-объяснение: "Dev Agent использует устаревшую библиотеку, я требую заменить, но он не справляется"
- Кнопки: написать подсказку Dev Agent'у / Force Approve / Re-plan

**Execution Cloaking (два таймера):**
- System Time: реальное время выполнения (например, 4 часа)
- Delivery Schedule: время, заявленное клиенту (например, 5 дней)
- Визуализация зазора между ними
- Scheduled messages: когда и что отправить клиенту
- `min_delivery_at` — "Готово. Отправка запланирована на пятницу, 14:00"
- Кнопка "Отправить прямо сейчас" для досрочной сдачи

**Остальные секции:**
- Header: title, platform badge, budget, delivery_type, relative time
- Revision Count: текущий revision / max (0/2)
- Details Card: description, budget_type, score, status, deadline, skills
- Client Info Card
- Bids Accordion: proposal_text, bid_amount, delivery_days
- Chat Section: все сообщения (AI + клиент + оператор), поле ввода, sender labels, real-time через WebSocket
- Critic Review Display: score, severity, issues list, revision target
- Plan Review Section: если HITL plan_review pending — показать план inline с кнопками approve/edit/reject
- Timeline: discovered -> bid -> in_progress -> completed/disqualified
- Disqualify Form: reason input
- "View on Platform" link

Главный рабочий инструмент для переговоров.

**Клик на карточку -> Chat Drawer (Sheet, w-[600px]):**

```
+------------------------------------------+
|  Chat: "React Dashboard"                 |
```

### 5. HITL Queue (`/hitl`)

Центральная очередь всех решений, требующих человека.

**Filter tabs:** All | Заказы | Bids | Reviews | Deliveries | Scope | Plans | Alerts

**Типы HITL (полный список):**

| Тип | Источник | Действия |
|-----|----------|----------|
| Bid Approval | Pipeline A | approve / edit / reject / later |
| Dev Launch | Pipeline A | approve / reject |
| Plan Review | Dev Cycle | approve / edit plan / reject -> replan |
| Critic Escalation | Dev Cycle | force approve / manual / re-plan |
| Partial Failure | Dev Cycle | resume / skip failed agent / manual |
| Final Delivery | Dev Cycle | approve / request_changes / reject |
| Lead Card | Pipeline B | approve / manual / skip |
| Concept Review | Pipeline B | approve / edit / reject |
| Concept Approved | Pipeline B | approve / hold |
| Design Review | Pipeline B | approve / revise (max 3) |
| Design Client | Pipeline B | approve / changes |
| Email Approval | Pipeline B | approve / edit / reject |
| Portfolio Review | Portfolio Agent | approve / edit |

**Карточка HITL:**
- Шапка: слева — цветной бейдж типа (URGENT: BID), справа — таймер "2h 15m"
- Контент: краткая выжимка (название, клиент, бюджет). Код/текст — сниппет в `font-mono`
- Кнопки действий на всю ширину:
  - Approve: `bg-emerald-600 hover:bg-emerald-500`
  - Edit: `bg-slate-800 hover:bg-slate-700`
  - Reject: outline, `text-red-400 border-red-900/50`
- Клик -> Detail Drawer с полной информацией + notes input

**Анимация Approve:** карточка `scale-95`, зеленоватый оттенок на 200мс, swipe вправо (Framer Motion).

**Фичи:** bulk resolve (select multiple -> fixed bottom bar: approve/reject/skip all), search, CSV export, stats summary (pending, resolved today, avg resolution time, expired).

**Plan Review (в drawer):**

## WebSocket Events

| Event | Данные | Что обновляет |
|-------|--------|---------------|
| `hitl:new` | title, type, id | HITL queue + dashboard widget + toast + desktop notification |
| `hitl:resolved` | title, id | HITL queue + stats |
| `agent:heartbeat` | agent, status, action, error | Agent Fleet + toast |
| `agent:log` | agent, level, message | Terminal PIP в Agent Detail |
| `project:update` | title, status, job_id | Jobs + toast |
| `bid:message` | bid_id, sender, content | Chat Drawer в Bid Kanban |
| `bid:status_change` | bid_id, old/new status | Kanban card move |
| `pipeline:progress` | job_id, agent, index, total | Pipeline Stepper |
| `lead:scored` | lead_id, temperature, score | Temperature badge |
| `scan:progress` | hex_done, hex_total, leads_found | Scan progress bar |
| `orch:status` | action | Orchestrator card |
| `orch:goal` | ... | Goals list |
| `orch:log` | ... | Orchestrator logs |
| `notification` | title, message | Toast + notification center |

**Подключение:** `ws://{host}/ws/events` + Bearer auth.
**Reconnect:** exponential backoff (max 30s), infinite retry, reconnect on tab focus.
**Status indicator:** зелёный/жёлтый/красный dot в header.

## Auth Flow

1. Login -> JWT access + refresh tokens -> Zustand persist -> redirect `/dashboard`
2. Register -> pending_approval -> ждёт owner approve
3. Auth guard в layout -> redirect `/login` если не авторизован
4. Auto-refresh на 401 -> retry original request
5. Roles: owner, co_owner, operator, viewer

## UX User Flows

### Персоны

| Персона | Основные задачи |
|---------|----------------|
| **Владелец** | HITL-одобрения, мониторинг агентов, аналитика, настройки |
| **Mobile (Telegram)** | Срочные HITL-решения с телефона |

### Flow 1: Утренняя рутина (10-20 мин)

```
Telegram (уведомления за ночь) → Dashboard KPI → HITL Queue → Projects дедлайны → Done
```

### Flow 2: HITL Approval (главный flow)

```
Queue → Классификация типа:
  ├── Bid      → Read → Edit? → Approve & Send / Skip / Later
  ├── Code     → Review → Approve / Request Fixes
  ├── Delivery → Preview → Deliver / Request Changes
  └── Alert    → Take Action / Acknowledge
```

Keyboard shortcuts: **A** (Approve), **S** (Skip), **E** (Edit) — работают при фокусе на карточке.

### Flow 3: Projects

**Freelance (заказы с бирж):**
```
Backlog → In Progress → Review → Done
```

**Цифровизация (локальные бизнесы):**
```
Идеи → [+ В очередь] → В разработке → Развёрнуто
```

Кнопка "Добавить в очередь" на карточках в колонке "Идеи" — ключевой элемент для Pipeline B.

### Flow 4: Agent Monitoring

```
System Health banner → Найти агента со статусом WORKING/ERROR → Live Log → Restart / Debug
```

### Flow 5: Geo Outreach

```
Выбор города → Радиус → Категории → Фильтр "без сайта" → Start Scan → Leads → Campaign
```

### Flow 6: Analytics

```
Выбор периода → KPI overview → Funnel анализ → Costs breakdown → ROI
```

Целевые метрики: Revenue, Win Rate (>20%), Response Time (<2h).

### Flow 7: Mobile HITL (Telegram)

```
Push-уведомление → Read card → [Approve] [Skip] [Later]
```

Команды бота: `/status`, `/pending`, `/stats`.

### Flow 8: Revision Handling

| Тип правки | Обработка |
|------------|-----------|
| Minor fix | Dev Agent auto-fix |
| Major issue | Planner → новый план |
| Scope creep | HITL → переговоры с клиентом |
| Unclear requirement | HITL → уточнить у клиента |

### Частота использования flows

| Flow | Частота | Критичность |
|------|---------|-------------|
| HITL Approval | 5-15x/день | High |
| Mobile HITL | По событию | High |
| Project check | 2-3x/день | Medium |
| Утренняя рутина | 1-2x/день | Low |
| Agent monitoring | 1x/день | Low |

### UX-рекомендации

1. **HITL Queue** занимает ~80% рабочего времени — keyboard shortcuts обязательны
2. **Dashboard** — instant overview за 5 секунд, без скролла до ключевых метрик
3. **Telegram** — 90% HITL-решений через мобильный, desktop для детальных ревью
