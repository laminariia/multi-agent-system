# Корпоративный сайт IT-компании

## Клиент
IT-компания **"NexGen Solutions"**, Москва. Ниша: B2B, аутсорс разработки. 40+ сотрудников, 80+ завершенных проектов, клиенты из России и СНГ. Старый сайт на WordPress (2019 года) не отражал уровень компании и плохо конвертировал.

## Задача
Компании нужен был премиальный корпоративный сайт, который бы соответствовал уровню их экспертизы и привлекал крупных B2B-клиентов. Основные требования: страницы услуг с детальным описанием, портфолио с фильтрами и кейсами, раздел команды, блог с SEO-оптимизацией, мультиязычность (RU/EN) для выхода на международный рынок, CMS для самостоятельного обновления контента.

## Решение
Разработал корпоративный сайт на Next.js с headless CMS (Sanity) для управления контентом без разработчика. Дизайн: минималистичный с акцентом на кейсы и экспертизу, анимации на Framer Motion (плавные transitions между страницами, параллакс, reveal-on-scroll). Структура: главная с hero-секцией и ключевыми метриками, 6 страниц услуг с интерактивными схемами процессов, портфолио с фильтрами по технологиям и индустриям (25 кейсов), страница команды с фотографиями и компетенциями, блог с MDX-поддержкой и автогенерацией OG-изображений, контактная форма с интеграцией в Bitrix24 CRM. SEO: SSR/SSG для всех страниц, структурированные данные (JSON-LD), автогенерация sitemap, оптимизация изображений (next/image, WebP, lazy loading). Мультиязычность через next-intl с отдельными URL (/en/, /ru/). Sanity Studio настроен с кастомными полями для каждого типа контента, preview в реальном времени.

## Результат
- **PageSpeed: 95+** на мобильных (было 42 на старом сайте)
- Органический трафик **+180%** за 3 месяца
- **12 заявок/мес** через сайт (было 2-3)
- Bounce rate снизился с **65% до 38%**
- Среднее время на сайте: **3:40** (было 1:15)
- Контент-менеджер обновляет сайт самостоятельно через Sanity

> "Сайт наконец-то выглядит как компания с оборотом 80 млн. Клиенты говорят, что именно сайт убедил их выбрать нас среди конкурентов. Первый международный контракт пришел через английскую версию." -- Максим Терехов, CEO NexGen Solutions
