# CRM-система для автосервиса

## Клиент
Автосервис "МоторПлюс", Новосибирск. 2 точки: Ленинский район (основная, 6 подъёмников) и Кировский район (3 подъёмника). 14 механиков, 3 приёмщика, 1 управляющий. Работает с 2019 года, специализация — японские и корейские авто. Владелец — Сергей Мартынов.

## Задача
Учёт вёлся в Excel: таблица клиентов, таблица заказ-нарядов, таблица запчастей — всё в разных файлах, данные между точками не синхронизировались. Приёмщики тратили 20-30 минут на оформление каждого заказа: вручную искали историю клиента, звонили на склад уточнить наличие. Клиенты забывали про плановое ТО и не возвращались. Нужна была единая CRM-система для обеих точек с учётом клиентов, историей ремонтов, складом и автоматическими напоминаниями.

## Решение
Разработал кастомную CRM-систему с веб-интерфейсом, заточенную под специфику автосервиса. Карточка клиента: ФИО, телефон, авто (марка, модель, год, VIN, пробег), полная история всех ремонтов и ТО по обеим точкам. Заказ-наряд: список работ с нормо-часами, запчасти со склада с автоподбором по VIN, автоматический расчёт стоимости (работа + запчасти + наценка). Складской учёт: приход/расход запчастей, минимальные остатки с уведомлениями, поиск по артикулу и кросс-номерам. Система напоминаний: за 2 недели до планового ТО клиент получает SMS и Telegram-сообщение с предложением записаться. Приёмщик видит на главном экране: кто записан на сегодня, какие машины в работе, какие запчасти в заказе. Управляющий: дашборд с выручкой по точкам, загрузкой подъёмников, средним чеком, топ-услугами. Фоновые задачи (напоминания, отчёты) обрабатываются через Celery с Redis-брокером. API на FastAPI для возможной интеграции с бухгалтерией в будущем.

## Результат
- Повторные визиты клиентов: +25% за первые 3 месяца
- Время оформления заказ-наряда: 5 минут (было 20-30 минут)
- Учёт склада: в реальном времени по обеим точкам, расхождения исключены
- Средний чек: +12% за счёт автоподбора сопутствующих работ
- Напоминания о ТО: 40% клиентов записываются после первого напоминания
- Потери запчастей (неучтённый расход): с ~15 000 руб/мес до 0
- Отзыв клиента: "Раньше приёмщик 10 минут искал в Excel, был ли клиент у нас. Теперь вбил номер телефона — и вся история: что делали, какие запчасти ставили, когда следующее ТО. Склад перестал 'худеть'" — Сергей Мартынов, владелец

## Стек
Python 3.12, FastAPI, React 18, PostgreSQL 16, Celery, Redis, Telegram Bot API, SMS Aero, Docker, Nginx
