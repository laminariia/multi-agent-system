# AI-агент рекрутинга для HR-агентства

## Клиент
HR-агентство "КадрПро", Нижний Новгород. Работает с 2019 года, специализация — подбор IT-специалистов и инженеров для производственных компаний. 6 рекрутеров, 2 аккаунт-менеджера. Средний поток — 25-30 активных вакансий одновременно. Руководитель — Ольга Назарова.

## Задача
Рекрутеры тратили по 4-5 часов в день на ручной скрининг резюме: скачивали отклики с HeadHunter, просматривали каждое CV, выписывали ключевые навыки, сравнивали с требованиями вакансии. На одну позицию приходило 80-150 откликов, из которых релевантными оказывались 10-15%. Оставшееся время уходило на составление сообщений кандидатам — шаблонные письма давали отклик менее 20%. Нужна была система, которая автоматически скринит резюме, ранжирует кандидатов по релевантности и генерирует персонализированные сообщения для первого контакта.

## Решение
Разработал AI-агента на базе LangChain с интеграцией в HeadHunter API. Система работает в три этапа. Первый — автоматический парсинг: агент получает новые отклики через HH API, извлекает структурированные данные из резюме (навыки, опыт, образование, зарплатные ожидания) и сохраняет в PostgreSQL. Второй — скоринг: LLM анализирует каждое резюме относительно требований вакансии, выставляет балл от 0 до 100 по 5 критериям (совпадение стека, релевантный опыт, уровень позиции, география, зарплатные ожидания) и формирует краткое резюме-выжимку на 3-4 предложения. Третий — генерация outreach: для кандидатов с баллом выше 70 AI генерирует персонализированное сообщение, учитывая конкретный опыт кандидата и специфику вакансии. Рекрутер видит дашборд: отсортированные кандидаты, баллы, резюме-выжимки, готовые сообщения. Одна кнопка — одобрить и отправить, или отредактировать перед отправкой. Все решения рекрутер принимает сам — AI только готовит материал и ранжирует. Реализовал дедупликацию кандидатов по email и телефону, чтобы один человек не получил два сообщения по разным вакансиям.

## Результат
- Время скрининга на одну вакансию: 15 минут (было 3-4 часа)
- Точность скоринга: 89% совпадение с оценкой рекрутера (проверка на 200 резюме)
- Отклик на персонализированные сообщения: 38% (было 19% на шаблонных)
- Рекрутер обрабатывает 8-10 вакансий в день вместо 3-4
- Время закрытия позиции: сократилось с 18 дней до 11 дней в среднем
- Отзыв клиента: "Раньше девочки сидели до вечера и листали резюме. Сейчас к обеду у них уже отранжированный список с готовыми сообщениями. За первый месяц закрыли на 40% больше позиций" — Ольга Назарова, руководитель

## Стек
Python 3.12, LangChain, OpenAI API (GPT-4o-mini), FastAPI, PostgreSQL 16, React 18, HeadHunter API, Celery, Redis, Docker

## Сроки
6 недель (анализ процессов и проектирование — 5 дней, backend: парсинг и скоринг — 12 дней, frontend: дашборд рекрутера — 8 дней, интеграция HH API и outreach — 5 дней, тестирование на реальных данных и калибровка — 5 дней)

### Platform Text (EN)

Built an AI-powered recruitment agent for an HR agency — automated resume screening and candidate ranking from HeadHunter (Russia's largest job board). The system pulls applications via HH API, uses LLM to analyze each resume across 5 criteria (tech stack match, relevant experience, seniority level, location, salary expectations) and assigns a score from 0 to 100. For top candidates (70+), AI generates a personalized outreach message based on the candidate's specific experience and job requirements. Recruiters see a dashboard with ranked candidates, resume summaries, and ready-to-send messages — approve and send in one click. All decisions stay with the recruiter; AI only prepares the material. Results: screening time per vacancy dropped from 4 hours to 15 minutes, candidate response rate increased from 19% to 38%, average time-to-fill reduced from 18 to 11 days. Tech stack: Python, LangChain, OpenAI API, FastAPI, PostgreSQL, React, HeadHunter API, Docker. Delivered in 6 weeks. Available for AI recruitment and HR automation projects.
